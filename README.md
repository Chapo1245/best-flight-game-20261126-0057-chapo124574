Island Hopper — Skyline Run: a complete flight game in static files. Fly one sortie over a coastal island — thread 5 golden rings, skim 3 coastal checkpoints low over the water, then put her down on Runway 27. Throttle, pitch and bank discipline matter: the wing stalls, the fuel runs out, and a hard touchdown bends the airframe. Chase view over sea, beach, fields and mountains, with altitude, speed and heading on the HUD, an artificial horizon, and a score for the whole sortie. No network, no build step — just open it and fly.

## Run it

```sh
python3 -m http.server 8080 --directory game
# open http://localhost:8080 in desktop Chrome, press Enter to fly
```
